# C - More malloc, free

This project covers `exit`, and the standard functions `calloc` and `realloc`.

## Learning objectives
- How to use the `exit` function
- What `calloc` and `realloc` are and how to use them

## Requirements
- Ubuntu 20.04 LTS, compiled with `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
- Betty style
- Only `malloc`, `free` and `exit` are allowed

## Files
| File | Description |
|------|-------------|
| `main.h` | Header file with all prototypes |
| `0-malloc_checked.c` | Allocates memory with `malloc`, exits with status 98 on failure |
