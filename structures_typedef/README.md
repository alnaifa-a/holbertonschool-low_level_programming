# C - Structures, typedef

This project covers structures and `typedef` in C.

## Learning objectives
- What structures are, and when, why and how to use them
- How to use `typedef`

## Requirements
- Ubuntu 20.04 LTS, compiled with `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
- Betty style
- Allowed functions: `printf`, `malloc`, `free`, `exit`
- Header files are include guarded
